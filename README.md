 # P2P Learning Platform

An AI-powered Peer-to-Peer Learning Platform that enables students
to exchange knowledge, discover compatible learning partners, and
collaborate through structured learning partnerships.

## About the Project

The P2P Learning Platform helps students connect based on their
academic fields, teaching skills, learning interests, languages,
and availability.

Students can teach what they know, learn what they want, and
collaborate through personalized learning partnerships.

## Key Features

- Student registration and authentication
- Academic field-based profile grouping
- Teaching skills and learning interests
- AI-assisted peer matching using Google Gemini
- Peer connection requests and introductory sessions
- Structured four-week learning partnerships
- Real-time messaging using Socket.IO
- Learning plans and session scheduling
- Google Meet and Google Calendar integration
- AI-generated assessments and answer evaluation
- Learning progress tracking
- Peer ratings and achievement badges
- Email notifications

## How It Works

1. Students register and complete their profiles.
2. They select their academic fields, teaching skills, and learning interests.
3. The system recommends compatible learning partners.
4. Students connect and complete an introductory session.
5. Both students confirm whether they want to continue.
6. A learning partnership is created with a learning plan.
7. Students collaborate, attend sessions, and complete assessments.
8. The platform tracks progress and awards ratings and badges.

## Project Structure

The application is organized into separate frontend, backend,
database, and documentation components.

- `client/` — React frontend
- `server/` — Node.js and Express backend
- `database/` — Database documentation and seed data
- `docs/` — Project requirements, architecture, and documentation
